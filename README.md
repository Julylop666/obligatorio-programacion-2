# Purr & Brew 2D

Juego cozy de cafetería en pixel art hecho con Python y Pygame para Programación 2 (Facultad de Diseño, Universidad ORT Uruguay).

- El juego, con su README completo (cómo se instala y se juega), está en la carpeta [`Purr_&_Brew/`](Purr_&_Brew/README.md).
- El informe (inspiración, diagrama de flujo, proceso creativo y afiche) es `Informe_MichiCafe2D_Lopez_78200.pdf`.

## Instalación rápida (Windows)

Se necesita Python 3.9 o superior. Si todavía no está instalado, se puede instalar Python 3.12 desde la terminal con:

```powershell
winget install --id Python.Python.3.12 --exact
```

Después de instalarlo, cerrá y volvé a abrir la terminal. Desde la carpeta del repositorio:

```powershell
cd "Purr_&_Brew"
py -m pip install -r requirements.txt
py main.py
```

Los pasos completos y los detalles de las dependencias están en [`Purr_&_Brew/README.md`](Purr_&_Brew/README.md).
